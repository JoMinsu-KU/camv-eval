# E1: finite empirical group-population simulation

Protocol date: 2026-11-04 (Asia/Seoul). This experiment is a post-review addition. It does not replace or alter any frozen scientific record. All computations and outputs use E: SATA HDD storage.

## Population and contrast

The source is the saved `collections.json.gz` score collection. Canonical seed 29 and the original development split define two finite populations. RLBenchFail has 40 groups, 106 trials (44 success, 62 failure), four cameras and six forward camera pairs. REASSEMBLE has 111 groups, 1,716 trials (1,595 success, 121 failure), three cameras and three forward camera pairs. The input manifest fixes every source sample and group identifier, score availability and pair. `bare` and `space` define four prespecified conditions. Joint scores are the stored forward-pair scores. Late scores are the sigmoid of the arithmetic mean of the two original Single log odds, using the same definition as the empirical analysis. All selected canonical records are available. No model inference is performed.

One population draw samples a source group uniformly, retaining its entire trial block, labels, score vectors, group size and within-group/camera/method dependence. Development and evaluation draws are independent. Their group-occurrence counts are fixed at 40/179 for RLBenchFail and 111/37 for REASSEMBLE; their trial counts are random. We do not trim, pad or redraw groups to obtain a desired trial or class count. A repeated source group is a distinct sampled occurrence, even though its observed block is identical.

Each original trial has total weight one. Its pair entries receive weight 1/P. For each scoring method, pooled calibration uses all P pairs; pair-specific calibration calibrates each pair. A threshold is the largest observed positive score satisfying weighted empirical success recall >= 0.9, with the existing 1e-12 constraint tolerance. The interaction is (Joint-pair minus Late-pair) minus (Joint-pooled minus Late-pooled), separately for false-success rate and success recall. The original success-positive score direction is retained.

## Arithmetic and sampling units

The new-law engine evaluates point estimates, bootstrap draws, exact fitted-policy truth and evaluation-delete jackknife values as an **exact signed integer acceptance numerator divided by P times the class denominator**. Signed counts are accumulated as integer-valued float64 numbers, well below the exact-integer representability limit. Scaling individual features by 1/P is reserved for sandwich influence calculations. This avoids artificial destruction of mathematical ties in BCa rank calculations from separately rounded component ratios. Comparison with the preserved legacy implementation uses an absolute tolerance of 1e-12; the implemented fixtures achieve at most 6.8e-16 point discrepancy.

An outer group-occurrence sample can be represented by origin-group multiplicities. Conditional on these counts, a bootstrap of occurrences is exactly a multinomial draw with probabilities equal to origin multiplicity divided by occurrence sample size. The compressed implementation is distributionally identical to resampling the explicitly expanded occurrence data. Sandwich squared influences are multiplied by occurrence multiplicity, not the square of an aggregated origin weight. BCa deletes one occurrence, then repeats each origin-specific delete value according to its occurrence multiplicity. Independent fixtures compare these calculations with explicitly expanded data, weighted threshold fits, exact repeated-count ratios and a Joint=Late exact-zero contrast.

## Targets and procedures

For each development sample D, fitted-policy truth tau(D) is evaluated exactly over the complete finite group population. Each class rate is a ratio of weighted acceptance sums and class-count sums; it is not an average of group-specific rates. The procedure-average target mu is E_D[tau(D) | V(D)], where V(D) requires both development classes and all thresholds to be finite. Independent reference draws estimate this target, starting at 65,536, doubling if any metric/condition has Monte Carlo standard error above 0.05 percentage points, with a cap of 262,144. The full reference arrays and validity counts are retained. Coverage at mu +/- 3 reference MCSE is reported as a sensitivity diagnostic. Failure to meet precision is an error, not a silent success.

There are M=1,000 outer datasets per condition and B=999 bootstrap draws. Both scorer variants use identical outer and bootstrap multiplicities. The five compared constructions are conditional percentile group-bootstrap, full-refit percentile, full-refit basic, conditional cluster-sandwich t, and full-refit cluster bias-corrected and accelerated (BCa). The percentile/basic methods use the preserved linear quantile and interval availability rule (at least 95% finite bootstrap draws). BCa uses the preserved two-sample cluster jackknife, exact-tie-adjusted z0, untruncated adjusted tails and recorded availability/status flags. No fallback interval replaces a failed construction.

Conditional percentile and conditional sandwich are target-matched to tau(D). The three full-refit constructions are evaluated against mu as their target-matched comparisons. All procedures are also evaluated against the other target, explicitly marked as cross-target diagnostics. Availability is reported separately; planned-denominator coverage counts unavailable intervals as not covering. Available-denominator coverage is also retained. A nominal 95% label is not an empirical coverage guarantee.

## Randomness, execution and outputs

NumPy SeedSequence root is [20261104, 48245, 1001]. Additional coordinates are cohort (0 RL, 1 RE), domain, outer index. Domains 10/20 generate development/evaluation outer samples; 30/40 generate development/evaluation bootstrap samples; domain 100 generates independent procedure-average references. Fixture domains 901-903 do not overlap the scientific streams. Reference prefix coupling is preserved when increasing its draw count. No outcomes from the pilot determine scientific inclusion or method settings.

The 10-outer paired runtime pilot and all numerical fixtures precede this freeze. The production runner verifies SHA-256 pins for the source, input manifest, engine, runner, preserved numerical core and this protocol before starting or resuming. At most two production workers run, with BLAS/OMP thread counts one. Each outer/scorer record is written atomically and can be resumed; saved metadata and draw shapes are checked on resume. All four conditions are reported, including interval failures. Stored draws, thresholds, class/trial counts, reference arrays, CI endpoints and diagnostics support numerical replay. Any subsequent protocol change requires a new versioned experiment directory.

The empirical population is a deliberately fixed resampling law. Its coverage findings describe these observed group blocks and this scoring/calibration procedure; they are not proof of coverage on a new robotics population or a general inference guarantee. No additional parameter tuning or frontier-model experiment is part of E1.

# Reproduction contract

## Inputs, targets, and expected outputs

The code compares joint-image scoring and late fusion under pooled and pair-specific recall thresholds. Thresholds use the maximum observed success-score knot satisfying empirical recall 0.90, including ties. Whole groups, overlapping camera pairs, development/evaluation separation, the original seeds, and the original unavailable request are retained.

Full mode invokes the previously validated numerical entry points, with relative paths and fresh output folders. The top-level wrapper verifies release SHA-256 hashes before extraction and after replay. Nested v3/v2 ZIPs are authenticated through their parent manifests. Each original entry point additionally validates its own files and comparisons. Quick mode reconstructs the original paired interaction and linear percentile limits rather than copying expected limits.

## Statistical interpretation

The interaction is `(Joint_pair − Late_pair) − (Joint_pooled − Late_pooled)`. Seeds are averaged before the paired interaction draws are summarized. Conditional intervals describe policies fitted on the observed development cohorts. Procedure-average targets average over repeated calibration at the specified finite development size. Conditional zero exclusion does not change the original Holm-adjusted refit FSR tests.

The original four FSR non-rejections do not establish an absent or negligible interaction. There was no prospective MDE/power-based empirical sample-size calculation. Simulation rejection rates characterize their specified generating conditions and are not estimates of empirical-cohort power. Continuous H050_C/H065_C/S_H_C recall rows coincide by translation equivariance, not by an indexing error. BCa midpoint/width diagnostics describe the tested grid; iterated bootstrap calibration is a future proposal, not an implemented validated method in this release.

## Environment and portability

Tested numerical versions: Python 3.11.16, NumPy 2.2.6, SciPy 1.16.2, pandas 2.3.2, Matplotlib 3.10.6, psutil 7.0.0. Full local validation uses a copied input directory, an existing separate interpreter, Windows, and E: SATA HDD. No environments or models are bundled. Python audit hooks in the legacy entry points constrain successful reads/writes after their installation; these are not OS or native-DLL sandboxes.

The new command line uses relative locations and is tested from a directory containing spaces. Historical absolute paths in frozen source and provenance are retained and are not used to find numerical inputs by these replay adapters. Linux/macOS, fresh installations, and other dependency versions remain unverified. A missing platform-specific runtime permission or floating-point difference should be reported, not hidden by disabling numerical checks or editing expected values.

Each run records status, stage logs, elapsed time, versions, and output hashes. Times are measurements of the test machine; they are not universal estimates. The release contains no evidence of an independent external researcher reproduction, new VLM calls, or full Monte Carlo regeneration.

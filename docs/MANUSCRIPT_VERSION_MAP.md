The v12 archive contains all 3,000 new outer datasets with 999 paired bootstrap draws each, 32,768 reference development datasets, frozen simulation source and profiles, and portable inputs for the saved-result diagnostics. The latter project the required fields of 16,000 older outer datasets while retaining original source hashes. The v8 assets remain unchanged. This is a software/data release supporting an author-review manuscript; it does not establish journal acceptance or a publication DOI.

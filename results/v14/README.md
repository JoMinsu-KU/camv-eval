# v14 result tables

`empirical_laws/` contains six E1 tables with an independently replayable saved-array source in the v14 asset. `empirical_audit/` and `statistical_audit/` contain selected A1–A7 audit-result snapshots; the v14 replay does not regenerate all their raw inputs. See index.json for exact asset paths and hashes. These browsable CSVs are copied without re-rounding and do not themselves count as a numerical reproduction. Conditional/fitted-policy and full-refit/procedure-average columns must retain their target labels. The original four-test family is unchanged.
